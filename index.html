How the Algorithms Work

Both methods sort the same data, but they make decisions differently.

Bubble Sort

Bubble Sort compares adjacent elements. If they are in the wrong order, they are swapped. After each pass, the largest unsorted value moves to the end.

  1. Compare adjacent elements.
  2. Swap when left > right.
  3. Repeat over the unsorted portion.
  4. The sorted suffix grows after every pass.

Selection Sort

Selection Sort searches the unsorted portion for the smallest value and places it at the beginning of that portion.

  1. Assume the first unsorted element is minimum.
  2. Scan the remaining elements.
  3. Remember the smallest value.
  4. Swap it into the current position.

C Program

Complete program used for the mini project.

#include <stdio.h>

void bubbleSort(int arr[], int n) {
    int i, j, temp;
    for (i = 0; i < n - 1; i++)
        for (j = 0; j < n - i - 1; j++)
            if (arr[j] > arr[j + 1]) {
                temp = arr[j]; arr[j] = arr[j + 1]; arr[j + 1] = temp;
            }
}

void selectionSort(int arr[], int n) {
    int i, j, min, temp;
    for (i = 0; i < n - 1; i++) {
        min = i;
        for (j = i + 1; j < n; j++)
            if (arr[j] < arr[min]) min = j;
        temp = arr[i]; arr[i] = arr[min]; arr[min] = temp;
    }
}

void display(int arr[], int n) {
    for (int i = 0; i < n; i++) printf("%d ", arr[i]);
    printf("\n");
}

int main() {
    int arr1[] = {64, 25, 12, 22, 11};
    int arr2[] = {64, 25, 12, 22, 11};
    int n = 5;
    printf("Original Array: "); display(arr1, n);
    bubbleSort(arr1, n); printf("Bubble Sort:    "); display(arr1, n);
    selectionSort(arr2, n); printf("Selection Sort: "); display(arr2, n);
    return 0;
}
